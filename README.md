# 🔐 Password Generator

## 📌 Project Overview

The **Password Generator** is a simple and user-friendly application developed to generate strong and secure passwords. It helps users create random passwords based on their required length and character types.

This project was developed as part of my **Decode Labs Internship** to practice programming concepts, user input handling, randomization, and basic security principles.

## ✨ Features

* 🔑 Generate random passwords
* 🔢 Choose password length
* 🔠 Include uppercase letters
* 🔡 Include lowercase letters
* 🔢 Include numbers
* 🔣 Include special characters
* 📋 Easy-to-use interface
* 🛡️ Helps create stronger passwords

## 🛠️ Technologies Used

* Python
* Random Module
* String Module
* HTML/CSS/JavaScript *(if applicable to your version)*

## ⚙️ How It Works

1. The user selects the required password length.
2. The application creates a character set based on the selected options.
3. Random characters are selected from the available character set.
4. A unique password is generated and displayed to the user.
5. The generated password can be copied and used for accounts or applications.
